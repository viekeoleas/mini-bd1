# Мини BD-1

Маленький двуногий робот в стиле BD-1 из Star Wars Jedi: Fallen Order.
ESP32 + 10 сервоприводов MG90S, рост около 235 мм, ходьба запрограммирована вручную.

## Статус (v0.7, 19 октября 2026) — проект на паузе

- [x] Детали куплены, напечатаны, ноги и таз собраны
- [x] Серво на PCA9685, прошивка: стойка, ходьба в воздухе, приседания, пульт с кнопками
- [x] Питание от блока 12 В через DC-DC; аккумулятор 2S с BMS и зарядкой собран
- [ ] Шагать по столу устойчиво: робот держит позу, но падает при шаге
- [ ] Питание от аккумулятора: XL4015 не работает ниже ~8 В, нужен UBEC (issue #1)
- [ ] Новая голова: окно под выключатель, полка под держатель, доступ отвёрткой к оси наклона
- [ ] Таз под PCA9685 со штырями, прорези под провода крупнее

Что пошло не так и почему, видно по `print/README.md` (версии v0.3–v0.7): модель проверялась только
на пересечения в собранном виде, а не на реальные размеры покупных деталей и не на саму сборку
(куда пройдёт штекер, как вставить серво, чем достать до винта). Новые детали стоит проверять этим.

## Что где лежит

| Папка / файл | Что это |
|---|---|
| `print/` | STL, уже повёрнуты для печати, + `print/README.md` с настройками и историей версий деталей |
| `print/T01_horn_fit_test_x1.stl` | пробная пластинка: 4 паза под одноплечую качалку MG90S с разным зазором |
| `firmware/` | прошивка ESP32 (PlatformIO): суставы в градусах, стойка, ходьба, приседания, восстановление шины I2C |
| `tools/pult.bat` | пульт с кнопками для ПК (Python + tkinter, порт находит сам) |
| `mini-bd1-assembly.step` | вся сборка с макетами серво, для любой CAD-программы |
| `cad/build_bd1.py` | скрипт, который строит модель в Fusion: все размеры в нём, правка и перезапуск пересобирают робота |
| `web/simulation.html` | 3D-симуляция 10 серво: походка, ручное управление каналами, нагрузки, центр тяжести |
| `web/drawings-v0.2.html` | черновые чертежи до модели (при расхождении права модель и документация) |
| `web/shopping-list.html` | список покупок со ссылками на arduino.ua |

HTML-страницы открываются в браузере двойным щелчком (нужен интернет: шрифты и 3D-библиотека грузятся с CDN).

## Ключевые цифры

| | |
|---|---|
| Голова | 116 × 72 × 53 мм: 2 × 18650, BMS, зарядка, ESP32, глаза, пищалка |
| Таз | 36 × 70 × 50 мм: DC-DC, PCA9685, MPU-6050 |
| Бедро / голень | 40 / 40 мм, колено вперёд |
| Между осями ног | 84 мм |
| Масса | ~470 г (оценка) |
| Каналы PCA9685 | 4–7 левая нога (бедро, колено, голеностоп, наклон стопы), 8–11 правая, 12 поворот шеи, 13 наклон головы (задаются в `firmware/src/main.cpp`) |
| Подключение | ESP32 3V3/GND/GPIO21/GPIO22 → PCA9685 VCC/GND/SDA/SCL; OE на плате перемкнуть на GND; серво — от DC-DC на клеммник V+ |
